# catherineawad.github.io

Personal portfolio site — hand-written static HTML/CSS, no frameworks, no build step.

Live at **https://catherineawad.github.io**

## Editing

- `index.html` — all content
- `css/style.css` — styling (light/dark via `prefers-color-scheme`)
- `assets/` — app screenshots (downscaled to 540px wide)

Push to `main` and GitHub Pages redeploys automatically.
